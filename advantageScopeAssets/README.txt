Custom AdvantageScope assets for Team 9143's robot "Leviathan".

  Robot_Leviathan/  Articulated 3D robot model for the 3D field view: config.json
                    and a README.md with the component order. The model binaries
                    (.glb) are NOT in the repository - the robot's CAD is not
                    distributed, and .glb / .step files here are git-ignored.
                    Export your own and drop them in (see the README.md inside).

To use them, select this folder in AdvantageScope with "Help > Use Custom Assets
Folder" (or copy Robot_Leviathan/ into the folder opened by "Help > Show Assets
Folder"). For the asset format, see the "Custom Assets" page of the AdvantageScope
documentation (the documentation tab in the app, or the URL below).

https://docs.advantagescope.org/more-features/custom-assets
